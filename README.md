# BungeePlugin

Proxy plugin for HomeMC, a Minecraft 1.8 server network I built in late 2025. Two jobs:
keeping player data in sync across backend servers, and forcing players back to the lobby
when a backend goes down.

## Where this went

The successor is [PRISMARIN](https://github.com/LeonManuel0705/prismarin), which runs on
Velocity rather than BungeeCord and handles the same fallback case plus maintenance mode,
MOTD and cross server messaging.

This repository is kept as it was. Archived.
